# Object storage, if the disk is not where you want the library

The default is a directory on the machine's disk, which is the right answer
until the library outgrows what the host will sell you, or until you would
rather the photographs were not on the same thing that gets destroyed by a
botched deploy. Then it is one variable:

```
STRATUS_STORAGE_DSN=s3://KEY:SECRET@<endpoint>/<bucket>?region=<region>
```

The endpoint is a host, the bucket is the path, and `region` is whatever the
provider calls it. The server writes, reads back and removes one object at
startup, so wrong credentials or a bucket it cannot write to stop the process
instead of surfacing on somebody's first upload. `/data` is still needed: the
indexer and the thumbnail generator spool through it.

## The one your host already sells

Cheapest in latency and usually in egress, because it is next door.

| Host | Its object storage |
|---|---|
| Fly | [Tigris](https://fly.io/docs/tigris/) — `fly storage create` makes a bucket and puts the keys in the app's secrets; copy them into one DSN. Endpoint `fly.storage.tigris.dev`, region `auto` |
| Render | [Render Object Storage](https://render.com/object-storage), S3-compatible and in early access at the time of writing |
| DigitalOcean | [Spaces](https://www.digitalocean.com/products/spaces) |
| Scaleway | [Object Storage](https://www.scaleway.com/en/object-storage/) |
| Hetzner | [Object Storage](https://www.hetzner.com/storage/object-storage/) |
| AWS | [S3](https://aws.amazon.com/s3/), which is the one the others are compatible with |

## The rest

| Provider | Worth knowing |
|---|---|
| [Cloudflare R2](https://developers.cloudflare.com/r2/) | No egress fees, region `auto` |
| [Backblaze B2](https://www.backblaze.com/cloud-storage) | Cheap per GB, free egress up to three times what you store |
| [Wasabi](https://wasabi.com/cloud-object-storage) | Flat per-TB, no egress or request charges, 90-day minimum retention |
| [Storj](https://storj.dev/dcs/) | Distributed, S3 gateway |
| [iDrive e2](https://www.idrive.com/e2/) | Cheap per GB |

Egress is the number to look at for a photo library: every phone that syncs and
every page of the gallery is traffic out. Storage per GB is the number
everybody advertises, and the one that will not be your bill.

## Running it yourself

| | |
|---|---|
| [Silo](https://github.com/pgsty/silo) | The MinIO fork the conformance suite runs against, which makes it the one implementation this server is actually tested on |
| [Garage](https://garagehq.deuxfleurs.fr/) | Small, no metadata server, built for a few machines in a cupboard |
| [Ceph RGW](https://docs.ceph.com/en/latest/radosgw/) | If you already have Ceph you already know |

A bucket on a LAN with no certificate takes `?tls=false`:

```
s3://KEY:SECRET@s3.lan:9000/stratus?tls=false
```

The index can move too, and the two decisions are independent:
[database.md](database.md).

Nothing else is tested, which is the honest way to put it: every provider above
speaks the S3 API, and the driver ([minio-go](https://github.com/minio/minio-go))
is the one most of them document themselves against, but the suite that runs on
every commit runs against Silo. A provider that breaks is a bug worth filing.
